LibertyClips Privacy Policy

Last updated: 26 November 2026

LibertyClips is a private tool used only by its owner to upload short video clips to the owner's own channels. It has no public sign-up and collects no data from visitors or viewers. This website sets no cookies and runs no analytics. The company hosting it may keep ordinary server logs.

Google user data the app accesses

The app requests the https://www.googleapis.com/auth/youtube.upload permission. It uses it only to upload videos, with their titles, descriptions and tags, to the owner's YouTube channel.

How that data is stored

  • The Google sign-in token is stored in a file on the owner's own computer.
  • The web addresses of uploaded videos are stored in a database on the same computer, so a clip is not posted twice.

Sharing

Google user data is not sold, shared or transferred to anyone else, is not used for advertising, and is not used to train AI models.

Google API Services User Data Policy

LibertyClips' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services, both to upload videos and to look up public information about videos and channels. Use of those services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access and deleting data

Access can be revoked at any time on the Google account permissions page. The owner deletes the stored token and database records from their computer when the app is no longer used, or on request.
